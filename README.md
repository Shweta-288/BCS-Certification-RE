# BCS Requirements Engineering – Supplementary Study Material

Extra resources to support the BCS Practitioner Certificate in Requirements Engineering course.

## What is in this repo

- Practice exercises and sample scenarios
- Case study handouts used during classroom activities
- slide for class diagram association and persona
- Answer sheets and model responses

## How to use this
1. Attempt the practice exercises before checking the answer sheet
2. Use the case study handouts to revise the classroom activities

## Notes

This material is meant to support your learning alongside the classroom sessions, not replace them. If anything is unclear, bring it up in the next session or reach out directly.
